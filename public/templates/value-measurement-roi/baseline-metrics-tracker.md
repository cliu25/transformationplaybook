## Purpose

*This tracker documents the current-state metrics that will be improved by your AI/automation initiative. These baseline measurements are critical for calculating ROI and demonstrating value realization.*

**Instructions:**
1. Identify 5-10 key metrics that your solution will impact
2. Define each metric clearly (how it's measured, what it includes/excludes)
3. Document the current baseline value with supporting data
4. Set realistic target values based on benchmarks or pilot results
5. Get Finance/EBM validation on all baseline values before proceeding
