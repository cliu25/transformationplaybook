View 3 · Worked example — before

State University enrollment — current state

The as-is enrollment workflow across three swimlanes. Red marks the pain points the team found: manual intake, one-by-one document verification, gut-feel outreach, and siloed data. Baseline metrics anchor the bottom — this is what success gets measured against.

State University enrollment — future state (MVP)

The to-be workflow with the two MVP AI interventions in teal: automated document verification and an enrollment-propensity model. The counselor feedback loop improves the model over time. Target metrics show what the MVP is built to achieve.
